- Apply MB.MD Pattern 40 (City Imagery Standardization) across:
  - Events
  - Professionals
  - Local groups
  - Recommendations

## 2.3 Navigation & Layout Issues
- Validate that all admin-only pages are properly permission-gated.
- Fix sidebar layout inconsistencies when switching between:
  - Feed
  - Events
  - Groups
  - Admin moderation
- Standardize top-level navigation for Admin mode vs User mode.

## 2.4 Data Integrity Fixes
- Ensure page-to-page sync for:
  - Event updates
  - Profile edits
  - New posts
  - Admin moderation actions
- Fix stale cache issues in:
  - Upcoming events sidebar
  - Friends sidebar
  - Notifications panel
- Add missing invalidation logic where needed.
