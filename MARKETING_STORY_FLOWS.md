# MARKETING STORY FLOWS
**Narrative-Based Screenshot & Video Sequences**

Version: 1.0.0

## STORY FLOW CONCEPT

Instead of isolated feature screenshots, story flows capture **complete user journeys** that demonstrate real-world use cases. Each flow tells a cohesive story from problem to solution.

---

## STORY FLOW 1: NEW DANCER DISCOVERY
**Target Audience:** Beginners, travelers
**Duration:** 90-120 seconds (video) or 8-10 screenshots
**Purpose:** Show how a new dancer discovers and engages with the platform

### Narrative Arc:
1. **Problem:** User is new to a city and wants to find tango events
2. **Discovery:** Opens Mundo Tango app
3. **Exploration:** Browses events discovery with filters
4. **Engagement:** Finds a milonga tonight
5. **Community:** Checks who else is going
6. **Connection:** Sends a message to attendees
7. **Preparation:** Gets directions and event details
8. **Satisfaction:** Saves event to calendar

## VIDEO PRODUCTION NOTES

### Video Editing Flow
1. Capture entire story sequence as one continuous screen recording
2. Add text overlays at key moments explaining user intent
3. Include subtle transitions between major steps
4. Add background music (tango-inspired, royalty-free)
5. Export in multiple formats (16:9, 9:16, 1:1)

### Video Metadata Template
```yaml
title: "[Story Name] - Mundo Tango"
description: "[2-3 sentence story summary]"
duration: "[XX]s"
target_audience: "[audience]"
platforms: ["website", "youtube", "social"]
cta: "Join Mundo Tango → [link]"
```

## USAGE GUIDE

### For Website
- Use Story Flow 7 (End-to-End) for homepage hero
- Use individual flows for feature pages
- Create GIF loops from key moments

### For Social Media
- Extract 15s clips from each flow for Stories/Reels
- Use screenshot sequences for carousel posts
- Create "swipe through" experiences on Instagram

### For Presentations
- Use full story flows for investor/partner pitches
- Screenshots work well in slide decks
- Videos create engaging demos

### For App Stores
- Story Flow 6 (Mobile) essential for app preview
- Use story screenshots for app store gallery
- Keep videos under 30s per App Store requirements
