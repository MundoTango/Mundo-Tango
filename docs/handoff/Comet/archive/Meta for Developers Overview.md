## Meta for Developers Overview

Meta for Developers provides tools and resources for building applications that integrate with Facebook and other Meta platforms, enabling features like social login, advertising, and content sharing. Developers can access APIs for AI, virtual reality, and business tools to connect users and grow businesses. The platform supports creating apps for web, mobile, and emerging technologies like Threads and Horizon.

## Getting Started as a Facebook Developer

To begin, log into your Facebook account and visit developers.facebook.com to create a developer account if needed. Select "My Apps" and click "Create App" to generate an App ID and Secret Key, choosing products like Facebook Login and specifying your platform (e.g., web or iOS). For login integration, add your site's URL to Valid OAuth Redirect URIs in the Facebook Login settings and configure permissions as required by your tool.

## Key Tools and APIs

- **Facebook Login API**: Allows users to authenticate with Facebook credentials on third-party apps, with settings for client OAuth and advanced access requests.
- **Marketing API**: Enables programmatic ad creation and management for businesses.
- **Threads API**: Supports integrations for creators to manage presence and share content at scale, launched in June 2024.
- **Graph API**: Core for accessing user data, posts, and pages, with access levels replacing older development modes.


## App Review and Development Mode

Apps start in development mode, limiting access to admins, developers, and testers added via Roles in the dashboard. To go live, submit for App Review in the dashboard, providing a privacy policy URL and ensuring compliance to avoid suspensions. Test users can be added manually since automated creation is temporarily disabled, and common issues include policy violations during setup.
